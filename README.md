# Simple AI Concept Explainer

This example demonstrates a very basic rule-based AI assistant. It simulates understanding user input by matching keywords and provides predefined answers about Artificial Intelligence concepts. This illustrates a fundamental principle of AI: making decisions based on input patterns.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Run the script using `python main.py`.
4. Type your questions about AI (e.g., 'Yapay zeka nedir?', 'nasıl çalışır?') and interact with the assistant.
